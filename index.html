Submission Guidelines

  • Automatic Unique ID

    Each submission receives a unique tracking ID (e.g., CMP-2026-1009) and starts in Pending status.

  • Clear Location & Context

    Include building name, floor, or room number so maintenance teams can locate the issue immediately.

  • Admin Triage & Priority

    Campus Administrators review incoming tickets, assign priority (Low to Urgent), and dispatch staff.

  • Image Size Guardrail

    Attachments are stored locally as Data URLs with a 500 KB limit to keep browser LocalStorage reliable.
